# MediPrescribe ⚕️
## نظام الوصفات الطبية الذكي — الأمراض الباطنية

نظام ويب احترافي (PWA) لتوليد الوصفات الدوائية آلياً لأمراض الباطنية، مبني على بروتوكولات
منظمة الصحة العالمية (WHO) والجمعيات الطبية العالمية (ADA, AHA/ACC, GOLD, GINA, IDSA...).

## المزايا
- 🔐 صفحة دخول آمنة بنظام صلاحيات RBAC (مدير / طبيب / صيدلي)
- 🏥 8 مستشفيات مسجلة في النظام
- 🩺 50 تشخيصاً باطنياً مع بروتوكولات دوائية كاملة (أدوية + مستلزمات + فحوصات + نصائح)
- ⚖️ حسابات جرعية تعتمد على الوزن (mg/kg) للأطفال
- 💾 حفظ محلي احترافي عبر IndexedDB (مرضى، وصفات، سجل تدقيق Audit Log)
- 🖨️ طباعة الوصفة الطبية بشكل رسمي
- 📱 قابل للتثبيت كتطبيق (PWA + Service Worker)

## بنية المشروع
```
mediprescribe/
├── index.html          # لوحة التحكم والوصفات
├── login.html          # صفحة تسجيل الدخول
├── css/style.css       # التنسيقات (ثيم كحلي داكن + ذهبي)
├── js/data.js          # 50 تشخيصاً + المستشفيات
├── js/db.js            # طبقة IndexedDB
├── js/app.js           # منطق التطبيق
├── manifest.json       # بيان PWA
└── sw.js               # Service Worker
```

> أو أي استضافة HTTPS، أما IndexedDB فيعمل مباشرة من المتصفح.

## تنويه طبي
البروتوكولات لأغراض العرض والتطوير، ولا تغني عن الحكم السريري للطبيب المعالج.
